## Bio para o site ("Sobre mim")

```
Cozinho porque acredito que comida boa muda o dia de alguém — não pela dieta,
mas pelo cuidado. Cada cardápio que crio é pensado para a rotina, os gostos e
os objetivos de quem vou servir: mais energia, mais prazer à mesa, mais tempo
livre para o que importa. Trabalho com ingredientes selecionados, técnica
apurada e atenção total a cada detalhe — do primeiro contato ao prato servido.
```

## Legendas de posts (exemplos)

**Post de lançamento:**
```
Abrindo agenda para clientes selecionados em São Paulo 🌿

Cardápios autorais, feitos sob medida para a sua rotina — sem fórmula
pronta, sem dieta genérica. Comida de verdade, no seu ritmo.

Vagas limitadas. Chama no WhatsApp (link na bio) para conversarmos sobre
o seu cardápio.
```

**Post sobre um prato/cardápio:**
```
Cardápio da semana para um cliente que pediu mais energia para os dias
corridos — proteínas de qualidade, vegetais de estação, zero complicação
na rotina dele. É esse o tipo de cardápio que gosto de criar: pensado
para a vida real de quem vou servir.
```

**Post institucional (processo/bastidores):**
```
Antes de qualquer cardápio, a primeira conversa é sobre você: rotina,
preferências, restrições, objetivos. Cozinha boa começa muito antes do
fogão. É assim que trabalho com cada cliente.
```

## Linhas de serviço (para o site, uma frase por pacote)

- **Essencial** — Meal prep semanal com cardápio autoral, pronto para a sua rotina.
- **Signature** — Meal prep + acompanhamento próximo para ajustar o cardápio ao
  seu objetivo de bem-estar.
- **Experiências** — Jantares privados e eventos com menu autoral, do início ao fim.
